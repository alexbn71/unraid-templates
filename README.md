# unRAID Templates

Central storage for unRAID Templates

## NuviraHub

Self-hosted remote desktop and remote support: [nuvirahub.dev](https://nuvirahub.dev).

- [nuvira-server](NuviraHub/nuvira-server.xml): the open source server (signalling, relay, app updates).
- [nuvira-server-pro](NuviraHub/nuvira-server-pro.xml): the Pro server, with server address books, accounts, web console and the other team features; needs a licence key.
